# EOT UX V2 — Acceptance Checklist

## Today
- [ ] One obvious learning focus
- [ ] One dominant CTA
- [ ] No module grid
- [ ] No fake Day count / weakness / score
- [ ] Learner-facing reason

## Lesson continuity
- [ ] Start appears once
- [ ] No Question X/Y
- [ ] No per-unit Ready screen
- [ ] Next step appears naturally
- [ ] Same learning focus remains coherent
- [ ] Internal primitive names invisible

## Teaching
- [ ] Can teach before failure
- [ ] Teaching move matches learner state
- [ ] Feedback matches actual primitive
- [ ] Reteach changes approach
- [ ] No Hint1→Hint2→Reveal-only flow

## 我還不會
- [ ] Works from SELECT
- [ ] Works from production
- [ ] No fabricated failure evidence
- [ ] Leads immediately to teaching
- [ ] No dead state

## Primitive quality
- [ ] SELECT has meaningful distractors
- [ ] RECALL hides answer
- [ ] COMPLETE is truly constrained
- [ ] Open PRODUCE uses semantic evaluation
- [ ] READING anchors to text evidence
- [ ] Writing strategy is not vocab recall

## Result / My English
- [ ] Result shows learning change, not score
- [ ] Assistance is honest
- [ ] No false stable/mastery
- [ ] My English allows sparse truth
- [ ] No fake percentages
- [ ] Frontier is clear and evidence-backed

## Journey
- [ ] Meaningful milestones only
- [ ] No session spam
- [ ] Feels like a long-term growth path

## Device
- [ ] Keyboard leaves CTA reachable
- [ ] Android Back coherent
- [ ] Resume preserves lesson
- [ ] Background time excluded
- [ ] No duplicate evidence
- [ ] No clipped text around 390px
- [ ] No debug surfaces

## Final human test
> If this were a free English app I had never seen before, would I voluntarily continue for another five minutes?

If the answer is “not really,” V2 is not done.
