# Q. Authentic Input / Materials

Q owns source/material identity and normalization, not learner ability or teaching policy.

Production boundary:

raw direct/paste/image/PDF intake
→ immutable OriginalArtifact
→ OCR/direct spans
→ role-separated AuthenticInputBundle
→ source-review gate when decision-relevant text is uncertain
→ H Writing or I Translation specialization

Q distinguishes PROMPT, RUBRIC, LEARNER_WORK and TRANSLATION_SOURCE. Unknown ownership remains `UNKNOWN`; Q must not silently relabel material as school/teacher/learner-owned.

Q never creates capability evidence. OCR/source confirmation is source truth only.

Future cross-app Capture remains outside current V1 scope.
