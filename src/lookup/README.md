# P. Contextual Lookup

P owns contextual lookup interaction and lookup exposure constraints.

Canonical learner rule:
- phrase/chunk first, then word fallback;
- concise zh-TW meaning in the current context;
- lookup is support/exposure, never proof that the learner can produce the language;
- normal learning checks lock only a lookup that would reveal the active target answer;
- formal assessment may lock lookup entirely.

Current wave deliberately does not invent meanings. Phrase discovery, contextual sense selection and grounded zh-TW explanations remain contract-only until the Data retrieval workstream is semantically integrated.

Any used lookup must contaminate later production as language assistance. Clearing the popover does not erase that exposure for the current opportunity.
