English Output Trainer MVP v0.3 patch

P0 fixes
- Robust Android keyboard visibility: dynamic keyboard-height padding plus scroll-to-answer.
- Error Bank and Progress screens stay dark across the full screen instead of turning white below short content.
- Tablet-friendly max-width layouts and iOS tablet support flag.
- Real tab icons instead of missing-glyph boxes.

Product architecture preview
- Organization demo for independent teachers, cram schools and schools.
- Seat-count concept (no price and no billing integration yet).
- Teacher view of learner ability snapshots: grammar, active vocabulary, retrieval, independent rate, tracked errors.
- Future Supabase migration draft for organizations, memberships, classes and class members.
- Data model uses "learner" roles so the product can later support non-school learners; GSAT remains the first market wedge.

Not included yet
- Real AI API grading.
- Photo/OCR import.
- Real organization authentication, invites or billing.
