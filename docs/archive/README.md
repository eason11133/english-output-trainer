- [../../README.md](../../README.md)

## Historical material

EOT intentionally preserves dated rebuild contracts, Codex prompts, reconciliation reports, closure reports, older UX contracts and audit artifacts because they document how the system evolved.

They are **not current product/status authority**, even when an old file originally used labels such as `AUTHORITATIVE`, `CURRENT`, `CLOSURE`, or `READY`.

The most misleading root-level historical documents have an explicit banner pointing back to `CURRENT_STATUS.md`. Other dated documents should be read as historical unless the current status file explicitly adopts them.

This cleanup does not delete or rewrite development history; it only separates current truth from historical process documentation.
