# EOT Wave H Writing — Integrated Major-Wave Candidate

Date: 2026-08-28  
Status: READY_FOR_AUDIT / NOT SEALED

## Product spine

Authentic learner/school prompt + immutable learner original → Writing work context → bounded high-value focus → D/E/F teaching → learner-authored revision → return to original → fresh-writing requirement → downstream G/K verification.

## Authority

H specializes Writing artifact/work semantics. It does not choose D's target, E's action, F's mechanism, C/K evidence status, or S/K exam score.

A Writing session can validly carry a grammar/vocabulary/chunk target selected by D; H must not require a `writing.*` target namespace.

## Source and authorship truth

- prompt/rubric and learner original are separate;
- OCR printed-prompt uncertainty is decision-relevant;
- confirmed printed prompt refreshes H source context;
- original revision is immutable;
- learner revision is versioned;
- AI suggestion / Teacher model is not learner-authored revision;
- fresh/transfer response is not written into source-revision lineage;
- return-to-original restores the latest learner revision and is not itself transfer/retention.
